## 🔧 Technical Implementation

### **WebSocket Server Features**

- **JWT Authentication**: Secure token-based connection validation
- **Connection Management**: Track active connections with metadata
- **Message Handling**: Support for AUTH, SUBSCRIBE, UNSUBSCRIBE, PING
- **Channel Permissions**: Role-based access control for subscriptions
- **Heartbeat System**: Automatic ping/pong for connection health
- **Error Handling**: Comprehensive error responses and logging

### **Redis PubSub Integration**

- **Pattern Subscription**: Subscribe to all channels using `*` pattern
- **Message Broadcasting**: Distribute events to subscribed connections
- **Scalable Architecture**: Support for multiple server instances
- **Event Filtering**: Channel-based message routing

### **Channel Permission System**

```typescript
const CHANNEL_PATTERNS = [
  { pattern: 'match:*', requiredRole: 'user', description: 'Match events' },
  { pattern: 'team:*', requiredRole: 'user', description: 'Team events' },

    requiredRole: 'user',
    description: 'Tournament events',
  },
  { pattern: 'admin:*', requiredRole: 'admin', description: 'Admin events' },
  { pattern: 'system:*', requiredRole: 'admin', description: 'System events' },

```

## 🌐 Message Protocol

### **Client Messages**

```typescript
// Authentication
{ type: 'AUTH', data: { token: string } }

// Channel subscription
{ type: 'SUBSCRIBE', data: { channels: string[] } }

// Channel unsubscription
{ type: 'UNSUBSCRIBE', data: { channels: string[] } }

// Heartbeat
{ type: 'PING' }
```

### **Server Messages**

```typescript
// Welcome message
{ type: 'WELCOME', data: { connectionId: string, serverTime: number } }

// Acknowledgment
{ type: 'ACK', data: { success: boolean, message?: string } }

// Real-time events
{ type: 'EVENT', data: { channel: string, event: RealtimeEvent } }

// Heartbeat response
{ type: 'PONG' }

// Error messages
{ type: 'ERROR', data: { code: string, message: string } }
```

## 🚀 Usage Example

```typescript
import { WebSocketServer, RedisPubSub } from '@ump/realtime';

// Create PubSub service
const pubsub = new RedisPubSub({
  host: 'localhost',
  port: 6379,
});

// Create WebSocket server
const server = new WebSocketServer({
  port: 8080,
  pubsub,
  jwtSecret: 'your-secret-key',
  pingInterval: 30000,
  connectionTimeout: 60000,
});

// Start server
await server.start();
```
