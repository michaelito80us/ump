## Technical Architecture

### Database Schema

```sql
-- Main partitioned table
CREATE TABLE audit_logs (
    id BIGSERIAL,
    timestamp TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    type VARCHAR(50) NOT NULL,
    actor_id UUID,
    message TEXT NOT NULL,
    -- Additional audit fields...
) PARTITION BY RANGE (timestamp);

-- Monthly partitions created automatically
-- e.g., audit_logs_2025_02, audit_logs_2025_03, etc.
```

### Key Functions

- `create_monthly_audit_partition()` - Creates new monthly partitions
- `ensure_audit_partitions()` - Ensures current and future partitions exist
- `audit_log_insert_trigger()` - Routes inserts to correct partitions
- `cleanup_old_audit_partitions()` - Removes old partitions

### Automation

- **Insert Trigger:** Automatically creates partitions on first insert
- **Constraint Exclusion:** Optimizes query performance
- **Index Inheritance:** Consistent indexing across partitions
