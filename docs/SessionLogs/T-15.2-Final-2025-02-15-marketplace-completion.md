## Errors Encountered and Corrective Actions

### 1. Accessibility Violation: Duplicate Banner Landmark

**Error Details:**
Document has more than one banner landmark

**Root Cause Analysis:**

- The marketplace page contains a `<header>` element for the page title
- The `CardHeader` mock in `marketplace.a11y.test.tsx` was also rendering a `<header>` element
- Multiple `<header>` elements create duplicate banner landmarks, violating WCAG accessibility standards

**Corrective Action:**

- **File Modified:** `g:/Ump/apps/mobile/src/app/[locale]/marketplace/__tests__/marketplace.a11y.test.tsx`
- **Change:** Modified `CardHeader` mock from `<header>` to `<div>` element
- **Code Change:**

```typescript
// Before
CardHeader: ({ children }: { children: React.ReactNode }) => <header>{children}</header>,

// After
CardHeader: ({ children }: { children: React.ReactNode }) => <div>{children}</div>,
```

- **Result:** ✅ Accessibility violation resolved

### 2. Multiple Install Buttons Test Failure

**Error Details:**
TestingLibraryElementError: Found multiple elements with text 'Install'
Unable to find an element with the text: Install

**Root Cause Analysis:**

- The test was using `getByText('Install')` which found multiple install buttons on the page
- The test needed to be more specific about which install button to target
- The `Card` mock was not preserving the `role="article"` attribute needed for proper element selection

**Corrective Actions:**

#### Action 1: Improved Button Selection Logic

- **File Modified:** `g:/Ump/apps/mobile/src/app/[locale]/marketplace/__tests__/page.test.tsx`
- **Strategy:** Use `within()` to scope button selection to specific plugin card
- **Code Implementation:**

```typescript
// Find the Rugby Plugin card and its install button
const rugbyPluginText = screen.getByText('Rugby Plugin');
const rugbyPluginCard = rugbyPluginText.closest(
  '[role="article"]'
) as HTMLElement;
const rugbyInstallButton = within(rugbyPluginCard!).getByRole('button', {
  name: /install/i,
});
```

#### Action 2: TypeScript Type Casting Fix

- **Issue:** `Element` type not assignable to `HTMLElement` when using `within()`
- **Solution:** Added explicit type casting with `as HTMLElement`
- **Code Fix:**

```typescript
const rugbyPluginCard = rugbyPluginText.closest(
  '[role="article"]'
) as HTMLElement;
```

- **Result:** ✅ Test now correctly identifies and clicks the specific install button
