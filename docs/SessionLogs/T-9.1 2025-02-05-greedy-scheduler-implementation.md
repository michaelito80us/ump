### Key Features Implemented

#### Core Algorithm

- **Earliest-slot first-fit algorithm**: Matches are assigned to the earliest available time slot that satisfies all constraints
- **Constraint parsing and validation**: Supports rest periods, blackout hours, and daily match limits
- **Graceful degradation**: Unscheduled matches are returned with clear reasons

#### Plugin Architecture

- **Plugin ID**: `greedy`
- **Capabilities**: `matches:unlimited`
- **Internationalization**: Full i18n support with English translations
- **Interface compliance**: Implements `SchedulingPlugin` interface from UMP engine

#### Constraint Support

1. **Rest Periods**: Minimum time between matches for teams/players
2. **Blackout Hours**: Time periods when matches cannot be scheduled
3. **Daily Limits**: Maximum number of matches per day per team/player

### Technical Implementation

#### GreedyScheduler Class Structure

```typescript
export class GreedyScheduler implements SchedulingPlugin {
  readonly id = 'greedy';
  readonly metadata: PluginMetadata;
  readonly capabilities = ['matches:unlimited'] as const;

  async scheduleMatches(
    request: ScheduleMatchesRequest
  ): Promise<ScheduleMatchesResponse>;
}
```

#### Algorithm Flow

1. **Parse constraints** from tournament configuration
2. **Sort pending matches** by ID for deterministic ordering
3. **Iterate through time slots** in chronological order
4. **Assign matches** to first available slot that satisfies constraints
5. **Validate assignments** and handle conflicts
6. **Return results** with scheduled and unscheduled matches
