### 🧮 **Mathematical Model**

- **Variables:** Binary decision variables `x[match][slot]` (1 if match assigned to slot, 0 otherwise)
- **Objective:** Minimize total scheduling conflicts and optimize resource utilization
- **Constraints:**
  1. Each match assigned to exactly one time slot
  2. No two matches can use the same slot simultaneously
  3. Venue capacity and availability constraints
  4. Time slot availability constraints
