## Technical Implementation Details

### **Core EventBus Features**

```typescript
// Enhanced EventBus with TypeScript generics
class EventBus<T extends EventMap = DefaultEventMap>
- subscribe<K extends keyof T>(event: K, handler: EventHandler<T[K]>): void
- unsubscribe<K extends keyof T>(event: K, handler: EventHandler<T[K]>): void
- publish<K extends keyof T>(event: K, data: T[K]): void
- listenerCount(event: keyof T): number
- eventNames(): (keyof T)[]
- removeAllListeners(): void
- removeAllListenersForEvent(event: keyof T): void
```

### **Type Safety Implementation**

- **EventHandler<T>**: Generic event handler interface
- **EventMap**: Base interface for event type mapping
- **DefaultEventMap**: Flexible default event types
- **createTypedEventBus<T>()**: Factory for type-safe event buses

### **Integration Points**

- **SandboxExecutor**: EventBus injected into plugin context
- **Plugin Context**: Access via `eventBus.publish()`, `eventBus.subscribe()`
- **Shared Store**: Coordinated with SharedStore for plugin state

## Plugin Communication Examples

### **Weather-to-Scheduling Plugin**

```javascript
// Weather Plugin publishes forecast
eventBus.publish('weather-plugin:forecast', {
  venue: 'Field A',
  forecast: 'rain',
  timestamp: Date.now(),
});

// Scheduling Plugin reacts to weather
eventBus.subscribe('weather-plugin:forecast', (data) => {
  if (data.forecast === 'rain') {
    adjustSchedule(data.venue);
  }
});
```
