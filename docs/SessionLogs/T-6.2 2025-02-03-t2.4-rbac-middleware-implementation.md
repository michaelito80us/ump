## Overview

Implemented comprehensive Role-Based Access Control (RBAC) middleware for the UMP Tournament Plugin System engine package, providing secure authorization for plugin execution and API access.

## Accomplishments

### 1. Core RBAC Implementation

- ✅ Created `packages/engine/src/rbac/requireRole.ts` with complete RBAC logic
- ✅ Implemented `@RequiresRole` decorator for method-level authorization
- ✅ Added function-based `requireRole` for flexible role validation
- ✅ Built utility functions: `validateUserRoles`, `hasAnyRole`, `hasAllRoles`
- ✅ Created `createRBACContext` for context management

### 2. Role Model & Types

- ✅ Defined comprehensive role hierarchy:
  - `OrgOwner` - Organization-level ownership
  - `OrgAdmin` - Organization administration
  - `TournamentAdmin` - Tournament management
  - `Referee` - Match officiating
  - `TeamManager` - Team administration
  - `Coach` - Team coaching
  - `Player` - Tournament participation
  - `Spectator` - View-only access
  - `PluginSystem` - System-level plugin access

### 3. Scope-Based Validation

- ✅ Implemented multi-level scope validation:
  - Organization scope (`organizationId`)

  - Match scope (`matchId`)

- ✅ Added scope inheritance and validation logic
