## Overview

Implemented comprehensive accessibility testing infrastructure for both admin and mobile applications using Playwright and axe-core to ensure WCAG 2.1 AA compliance and automated CI validation.

## Implementation Summary

### Dependencies Added

- `@playwright/test` - End-to-end testing framework
- `@axe-core/playwright` - Accessibility testing integration
- Added to both `apps/admin/package.json` and `apps/mobile/package.json`

### Configuration Files Created

- `apps/admin/playwright.config.ts` - Playwright configuration for admin app
- `apps/mobile/playwright.config.ts` - Playwright configuration for mobile app
- Both configured with multiple browsers (Chromium, Firefox, Webkit, Mobile Chrome, Mobile Safari)
- HTML reporter enabled with artifact collection

### Test Suites Implemented

- `apps/admin/tests/e2e/a11y.spec.ts` - Comprehensive accessibility tests for admin app
- `apps/mobile/tests/e2e/a11y.spec.ts` - Comprehensive accessibility tests for mobile app

#### Test Coverage

- **WCAG 2.1 AA Compliance** - Full page accessibility scanning
- **Color Contrast** - Ensures sufficient contrast ratios
- **Keyboard Navigation** - Tab order and focus management
- **ARIA Labels** - Proper labeling for screen readers
- **Heading Structure** - Logical heading hierarchy
- **Form Labels** - All form inputs properly labeled
- **Image Alt Text** - Alternative text for images
- **Mobile-specific Testing** - Touch targets and responsive design

### CI Integration

- Updated `.github/workflows/ci.yml` with new `accessibility` job
- Runs accessibility tests for both admin and mobile apps
- Installs Playwright browsers automatically
- Uploads test reports as artifacts
- Fails CI pipeline on accessibility violations
