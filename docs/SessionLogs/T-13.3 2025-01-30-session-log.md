  - Configured proper endpoint for Jaeger collector at `http://localhost:4317`

### 2. Context Propagation Fix

- **Issue:** Nested spans were not properly inheriting trace IDs from parent spans
- **Solution:** Enhanced the `instrument` method in `otel.ts` to use OpenTelemetry context propagation
- **Implementation:** Used `context.with(trace.setSpan(context.active(), span), ...)` to ensure proper span nesting
- **Result:** Parent-child relationships now work correctly with proper trace ID inheritance
